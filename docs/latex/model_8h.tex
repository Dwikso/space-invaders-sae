\doxysubsection{Detailed Description}
Définition du modèle de données (Data Model) du jeu Space Invaders. 

Ce fichier contient toutes les structures de données représentant l\textquotesingle{}état du jeu, les constantes de gameplay, ainsi que les prototypes des fonctions de manipulation du modèle (MVC).
