\doxysubsection{Detailed Description}
Constantes globales et configuration générale du projet. 

Ce fichier contient les paramètres fondamentaux qui sont partagés entre le Modèle, la Vue et le Contrôleur. Il définit notamment les dimensions abstraites du jeu (indépendantes de l\textquotesingle{}affichage) et les contraintes de performance (FPS, limites mémoire).
